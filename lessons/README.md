# فيديوهات مراجعة الدراسات الاجتماعية – الصف العاشر (الفصل الأول)

ومؤثرات صوتية وموسيقى مولّدة برمجياً.

المجموع: 11 فيديو (~103 دقيقة، ~370 ميجا). الفيديوهات بدقة 1280×720 و24 إطاراً/ثانية، والصوت مؤثرات وموسيقى فقط (بلا تعليق صوتي).

## ملاحظة عن الشخصيات الإسلامية
لا يُجسَّد الرسول ﷺ ولا الصحابة ولا الخلفاء ولا الأئمة بوجوه أو شخصيات. تُروى القصص بالخرائط والرايات
(جيوش على شكل بيادق بلا ملامح) واللوحات الاسمية، ويُمثَّل كل عالم بعمامة ملوّنة وكتاب.

## كيف يعمل
```
content/<lesson>.js     نص الدرس على شكل مشاهد (كل معلومة من الملف)
engine/                 محرّك الموشن غرافيك (HTML/CSS/JS) يُصوَّر بـ Chromium إطاراً إطاراً
blender/                مجسّمات Blender (برمجية بالكامل): الشخصيات، الجيولوجيا، المدن...
audio/synth.py          المؤثرات والموسيقى (numpy)، وتُركَّب من قائمة الإشارات التي يخرجها المحرّك
tools/produce.py        ينتج الفيديو النهائي: إطارات → صوت → mp4
```

## الفيديو المجمّع (≈ 1:43:49)
الإطار الأول يعرض وقت بداية كل درس ومدته؛ وتُحسب الأوقات تلقائياً من مدد الفيديوهات الفعلية:
```bash
.venv/bin/python lessons/tools/make_all.py     # يولّد content/index.js ثم videos/index.mp4 ثم videos/all_lessons.mp4
```
ملف `all_lessons.mp4` (~390 ميجا) مرفوع عبر Git LFS لأن حدّ GitHub للملف العادي 100 ميجا؛ ويمكن إعادة بنائه بالأمر أعلاه، أو دمج الملفات الفردية بـ `videos/concat.txt`:
```bash
cd lessons/videos && ffmpeg -f concat -safe 0 -i concat.txt -c copy all_lessons.mp4
```

```bash
# من جذر المستودع (بعد: pip install -r requirements.txt numpy scipy)
.venv/bin/python lessons/render_assets.py u1l1          # يرندر مجسّمات درس/مجموعة (Cycles على CPU)
.venv/bin/python lessons/tools/produce.py u1l1          # ينتج lessons/videos/u1l1.mp4
node lessons/tools/render.cjs u1l1 --shots 5,60,120     # لقطات سريعة للفحص
```

سرعة القراءة المعتمدة 2.3 كلمة/ثانية؛ كل نص يبقى على الشاشة بقدر وقت قراءته وتتلوّن كلماته تباعاً.
لقطات المجسّمات المتحركة (`assets/seq/`) لا تُرفع إلى Git؛ تُعاد بتشغيل `render_assets.py`.
